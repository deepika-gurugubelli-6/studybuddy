# StudyBuddy - Smart Study Group Matcher

A backend system that helps students find, create, and join relevant study groups based on subject and availability.

## Features

- User Registration & Login
- Create Study Groups
- Join Request System (Accept / Reject)
- Smart Group Suggestions based on subject
- Study Session Scheduling
- Attendance Tracking
- Role-based access (Admin / Member)

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- REST APIs
- Lombok

## How to Run

1. Clone the repository
2. Create a MySQL database named `studybuddy`
3. Update `application.properties` with your MySQL username and password
4. Run the Spring Boot application
5. Use Postman to test the APIs

## Base URL

http://localhost:8080
